내 LLM 키 (BYOK)

Tollm은 본인이 등록한 LLM 프로바이더 키로만 요청을 내보냅니다. 키를 등록하지 않으면 채팅 테스트가 "키를 등록하라"며 막혀요. 비용은 각자 본인 OpenAI/Anthropic 계정으로 청구됩니다. 등록한 키는 암호화되어 저장되고, 이 화면엔 마스킹된 일부만 보입니다(원문은 다시 표시되지 않음).

프로바이더는 자동으로 openai/anthropic이 채워지지만, 직접 수정해 다른 회사(예: kimi)도 등록할 수 있어요. 단, 지금 실제 프록시 호출은 openai/anthropic만 지원합니다(다른 프로바이더 라우팅은 추후).

채팅 테스트 (프록시 실호출)

⚠ 서버에 실제 OPENAI_API_KEY/ANTHROPIC_API_KEY가 설정돼 있어야 정상 응답이 옵니다. 미설정 시 502(PROVIDER_ERROR)가 정상입니다. 두 번째 호출의 응답 시간이 크게 짧으면 exact 캐시 히트입니다.

레이트리밋 데모 (토큰 버킷)

서버 설정: capacity=10, refillPerSec=1 (10개 버스트 허용 후 초당 1개씩 리필). 11번 연속으로 빠르게 보내면 마지막 요청은 429가 뜨는 것이 정상입니다.

팀 LLM 키 (BYOK)

팀 키(tlm_...)로 보낸 요청은 이 팀이 등록한 LLM 키로 나갑니다. 등록 안 하면 팀 채팅이 막혀요. 비용은 이 팀 키의 소유 계정으로 청구됩니다. 팀원이면 등록/삭제할 수 있고, 원문은 저장 후 다시 표시되지 않습니다.

프로바이더키(마스킹)등록일

팀 API 키

발급된 팀 키(tlm_...)는 "채팅 테스트"·"레이트리밋 데모" 탭에도 그대로 붙여넣어 쓸 수 있습니다 - 팀 키는 개인 키와 동일한 방식으로 인증되고, 쿼터/레이트리밋만 팀 단위로 집계됩니다.
